# sunstonedatasystems.com

Static marketing site for Sunstone Data Systems. Plain HTML, CSS, and a little JavaScript. No build step, so Vercel serves the files as they are.

## Pages
| File | Page |
|---|---|
| `index.html` | Home (hero, services, Built for GCs, process, markets, CTA) |
| `services.html` | All six services with included / excluded scope (anchor links per service) |
| `how-we-bid.html` | Bid format and what to send |
| `about.html` | Company, how we're set up, who we work with |
| `request-a-bid.html` | Bid request form |
| `privacy.html`, `404.html` | Privacy and not-found pages |

Brand files are in `brand/` (PNG) and `assets/img/` (SVG).

## Editing
Header, footer, and page text are generated by `tools/build_site.py`. Edit the text there, then run:

```
python3 tools/build_site.py
```

Small one-off edits can also go straight into the `.html` files, but they'll be overwritten the next time the script runs.

Preview locally: `npx http-server .` and open http://localhost:8080.

## Before launch: confirm these
- **Email**: the site uses `contact@sunstonedatasystems.com`. Create that mailbox (or forward it) in GoDaddy / Microsoft 365 / Google Workspace, or change `EMAIL` in `tools/build_site.py`.
- **Service area**: the site says "Dallas–Fort Worth and Texas" (assumed). Change in `tools/build_site.py` if wrong.
- **Phone**: not shown yet. Add it to the header/footer when ready.
- **Licensing, insurance, certifications**: About page says "available on request". Replace with real license numbers and certifications once confirmed.
- **Form**: see below. Until it's connected, the form opens the visitor's email app with the request filled in.

## Connect the bid form (5 minutes)
1. Create a free account at https://formspree.io and add a new form that emails `contact@sunstonedatasystems.com`.
2. Copy the form ID (the part after `/f/`).
3. In `tools/build_site.py`, replace `YOUR_FORM_ID` with it and run the build script (or edit `request-a-bid.html` directly).

## Deploy: GitHub → Vercel → GoDaddy
1. **GitHub**: create an empty repo (e.g. `sunstone-website`) and push this folder to it.
2. **Vercel**: at https://vercel.com/new, sign in with GitHub, import the repo. Framework preset: **Other**. No build command, output directory `.` (defaults are fine). Deploy. Every push to `main` redeploys.
3. **Domain**: in Vercel → Project → Settings → Domains, add `sunstonedatasystems.com` and `www.sunstonedatasystems.com`. Vercel shows the exact DNS records to add.
4. **GoDaddy**: My Products → sunstonedatasystems.com → DNS → Manage DNS:
   - Edit the **A** record for `@` to the IP Vercel shows (usually `76.76.21.21`). Delete any other `@` A records and GoDaddy "Parked"/forwarding entries.
   - Edit the **CNAME** for `www` to the value Vercel shows (usually `cname.vercel-dns.com`).
   - Leave MX / email records alone.
5. Wait for Vercel to show "Valid Configuration" (minutes to a few hours). Vercel issues the HTTPS certificate automatically.
